# Hotword Android

**Русский** · [English](README.en.md)

Открытый экспериментальный Android-проект: локально распознаёт выбранную пользователем **русскую ключевую фразу** и пытается вызвать **системного голосового помощника, назначенного по умолчанию**. Нет зависимости от Алисы, Gemini или другого конкретного поставщика.

## Исправления 0.3.1

- Исправлен вызов: теперь запускается **только экспортированный обработчик ассистента, выбранного в настройках Android**. Неоднозначные неявные Intent больше не используются, чтобы HyperOS не показывала меню всех помощников. Сначала проверяется `ACTION_ASSIST` конкретного выбранного пакета, затем `ACTION_VOICE_COMMAND` только в том же пакете. Если выбранный помощник не имеет доступного обработчика, приложение покажет ошибку вместо случайного выбора.
- Для фонового прослушивания включён `START_STICKY` и добавлено удержание CPU с ограниченными продлеваемыми `PARTIAL_WAKE_LOCK` на время работы сервиса. **Это может заметно увеличивать расход батареи.** Android/HyperOS всё ещё могут принудительно завершить приложение; точное поведение проверяется на устройствах.
- На Xiaomi 14 ранее подтвердили срабатывание на погашенном экране в версии 0.2. Версия 0.3.1 с изменённым механизмом требует повторного тестирования.
- Важное ограничение: публичные API не позволяют воспроизвести привилегированный системный жест ассистента в точности. Если у выбранного приложения нет доступной `Activity` для системного `ACTION_ASSIST`, приложение не сможет гарантировать тот же голосовой интерфейс.
- **После перезагрузки/принудительной остановки** необходимо снова открыть приложение: Android не даёт обычному приложению незаметно запускать микрофонный foreground service из фонового `BOOT_COMPLETED`.

### Диагностика

Если ассистент не открывается, сначала проверьте кнопку проверки выбранного помощника, не изменяя ключевую фразу. Затем проверьте работу со свёрнутым приложением и погашенным экраном. В Logcat фильтруйте сообщения по `HotwordAssistant` и `HotwordService`. Не путайте ограничения Android на запуск интерфейса помощника с остановкой самого распознавания.


## Версия 0.3 — автоматическое прослушивание

- Русская офлайн-модель Vosk **включена в готовый APK**; приложению не требуется интернет. При первом открытии модель один раз распаковывается в закрытое хранилище.
- После подготовки модели и выдачи разрешения на микрофон прослушивание **запускается автоматически**. Кнопок «Старт» и «Стоп» нет. Введённая фраза сохраняется автоматически после 1,5 секунд без ввода; только распознаватель перезапускается внутри работающего фонового сервиса без потери самого сервиса.
- Для запуска применяется адресованный выбранному ассистенту `ACTION_ASSIST`, а `ACTION_VOICE_COMMAND` используется только как резервный вариант внутри того же пакета; неявный вызов меню всех помощников запрещён. Микрофон освобождается на 20 секунд после распознавания.
- Разрешения микрофона и уведомлений проверяются внутри приложения. Проверяются доступные стандартные состояния оптимизации батареи и ограничения фоновой работы Android. Есть переходы в настройки энергосбережения и (для совместимых Xiaomi) автозапуска.
- В шторке остаётся минимальное уведомление о работе микрофона: **убрать его полностью нельзя** — это требование Android для долгоживущего microphone foreground service. Технические уведомления больше не выводятся при каждом распознавании. Сообщение об ошибке появляется только при сбое.
- После перезагрузки или обновления приложения, если уведомления разрешены, появляется напоминание открыть приложение для возобновления прослушивания. На Android 14+ автоматический запуск микрофонного foreground service из `BOOT_COMPLETED` запрещён платформой.

### Первоначальная настройка

1. В настройках Android выберите цифрового помощника по умолчанию и проверьте, что он способен принимать голосовые команды.
2. Установите APK, откройте приложение и дождитесь распаковки модели. Разрешите микрофон и, желательно, уведомления. Прослушивание запустится без отдельной кнопки.
3. Откройте настройки батареи и выберите **«Без ограничений»**. Для HyperOS отдельно откройте **«Автозапуск»** и разрешите приложению работать в фоне. Проверьте ограничения в карточке приложения.
4. Измените фразу по необходимости. Через небольшую паузу настройки применятся автоматически.

**Важно:** публичный Android API **не позволяет проверить** переключатель автозапуска в HyperOS или изменить его программно. Соответствующая кнопка лишь открывает доступную страницу настроек; при недоступности открываются сведения о приложении. Стандартные проверки батареи Android **не заменяют** проверки фирменных ограничений Xiaomi.

### Ограничения Android

Это не привилегированный системный компонент. `ACTION_VOICE_COMMAND` / `ACTION_ASSIST` — публичные способы обращения к помощнику, но **ни один из них не гарантирует** точную копию системного жеста, голосовую сессию или обход ограничений запуска Activity из фона/на экране блокировки. Поведение определяется устройством, версией Android и выбранным помощником. Если Android не позволяет вызвать помощника, возможен запасной вариант по уведомлению при явной ошибке.

**Круглосуточное прослушивание без единого исключения также не гарантируется**: система может отозвать разрешение микрофона, остановить процесс, отключить микрофон или перезагрузить устройство. Android 14+ запрещает запускать микрофонный foreground service из фонового `BOOT_COMPLETED` даже при включённом автозапуске Xiaomi. Поэтому при перезагрузке требуется хотя бы один пользовательский запуск приложения; уведомление напоминает об этом, если доставлено.

Непрерывное Vosk ASR энергоёмко и может пропускать произвольные слова или ошибочно узнавать похожие фразы. В будущем можно использовать специализированный low-power wake word detector; интерфейс `WakeWordEngine` отделён от сервисной логики.

## Исправления 0.3.2: вызов из фона и быстрый повтор

В Android 10+ `startActivity` из фонового сервиса может **молча блокироваться**, даже если распознавание на заблокированном экране продолжает работать и `startActivity` не выбрасывает исключение. `WAKE_LOCK` удерживает процессор, **но не даёт привилегий запуска Activity**. Приложение не подменяет выбранного системного помощника.

Чтобы на совместимых устройствах получить право на вызов выбранного помощника вне открытого Hotword:

1. Откройте приложение и нажмите **«Разрешить отображение поверх окон»**. Явно разрешите специальный доступ Android. Это **необязательное** расширенное разрешение; приложение никогда не включает его самостоятельно.
2. Во время прослушивания появится **маленькая видимая точка** у края экрана. Она не перехватывает нажатия и не считывает содержимое окон. На Android 15 наличие разрешения без действительно видимого overlay может оказаться недостаточным для запуска чужой Activity.
3. Проверьте вызов на домашнем экране и в другом приложении. **На экране блокировки системные окна могут скрывать overlay**; стабильный бесконтактный запуск там пока не гарантирован. Если Android/HyperOS блокирует попытку, нужен отдельный системно-привилегированный механизм или иной подход.

Ранее после каждого срабатывания сервис полностью выгружал модель Vosk и **ждал фиксированные 20 секунд**, из-за чего казалось, что микрофон сломан. Теперь модель остаётся в памяти. Сервис останавливает только захват звука, отслеживает доступные сведения о другом активном микрофоне и возвращается к распознаванию примерно через 3 секунды, **если ассистент не начал запись**, либо спустя 0,8 секунды после завершения другой записи. При противоречивых данных действует аварийный предел 30 секунд. Если Android не предоставляет информацию о чужих микрофонах, используется трёхсекундное ожидание, поэтому возможны конфликты на отдельных прошивках.

В настройках появился скрываемый блок **«Локальная диагностика»**: он показывает начало распознавания, срабатывание фразы, попытку запуска помощника и возобновление. Нажмите **«Скопировать события»**, если помощник не появляется: так можно отличить нераспознанную фразу от блокировки фонового запуска. Распознанные слова и аудио не сохраняются. Стандартное обязательное Android-уведомление о microphone foreground service остаётся без отладочного спама.

**Важно:** не предоставляйте разрешение «Поверх окон», если вас не устраивает постоянная видимая точка поверх других приложений. Без него обычный Android может запрещать автоматический запуск помощника, когда Hotword не на экране. Проверка работы на Xiaomi 14 и экране блокировки требуется после установки APK.

## Сборка

Нужны JDK 17, Android SDK 35 и Gradle 8.13. Для соблюдения размера и лицензирования репозитория архив русской модели **не коммитится** в Git: сборочный скрипт загружает закреплённый ZIP, сверяет SHA-256 и добавляет в `assets` **на машине сборки**. В готовом APK модель уже есть.

```sh
bash scripts/prepare-bundled-model.sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

При сборке офлайн положите официальный `vosk-model-small-ru-0.22.zip` по пути `app/src/main/assets/models/ru.zip`. Контрольная сумма фиксирована в `models/ru.sha256`; Gradle проверит её. GitHub Actions также проверяет модель внутри готового APK. Скачайте тестовый APK из **Actions → Android CI → Artifacts → hotword-debug-apk**.

## Архитектура

`MainActivity` отвечает за настройку и автоматический запуск, `DeviceSetup` за проверяемые системные параметры, `ModelInstaller` за локальную распаковку, `WakeWordService` за микрофон и восстановление после временных ошибок, `WakeWordEngine` за распознавание, `AssistantLauncher` за независимый от бренда системный вызов, `BootReceiver` за напоминание после перезагрузки.

## Конфиденциальность и вклад

Звук обрабатывается локально и не сохраняется; у приложения нет разрешения `INTERNET`. Сервис запускается после выдачи разрешения на микрофон, а использование микрофона обозначается системным индикатором. Если необходимо остановить прослушивание, можно отозвать доступ к микрофону или принудительно остановить приложение в настройках Android. См. [CONTRIBUTING.md](CONTRIBUTING.md). Код — [MIT](LICENSE); встроенная русская модель Vosk распространяется на условиях Apache 2.0, библиотека Vosk и прочие зависимости — на своих условиях.
