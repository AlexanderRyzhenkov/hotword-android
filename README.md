# Hotword Android

**Русский** · [English](README.en.md)

Открытый экспериментальный Android-проект: распознаёт **произвольную настраиваемую ключевую фразу** локально и пытается открыть **цифрового помощника, выбранного пользователем в настройках Android**. Нет привязки к конкретному помощнику, включая Алису или Google.

> **MVP:** Android может запретить вызов помощника из фонового приложения, особенно при заблокированном экране. После распознавания доступно уведомление для ручного открытия. Полностью бесконтактная работа на конкретных устройствах пока не гарантируется.

## Что доступно

- Встроенная **русская офлайн-модель Vosk**. Она уже включена в APK: загрузка, ручной импорт и интернет на телефоне **не требуются**. При первом запуске APK-модель распаковывается в закрытое хранилище приложения, после чего кнопка запуска прослушивания становится доступной.
- Можно задать любую русскую ключевую фразу (её фактическое распознавание зависит от словаря и качества модели). При изменении фразы прослушивание необходимо перезапустить.
- Микрофон обрабатывается только локально, звук не сохраняется и не отправляется на сервер. Приложение **не запрашивает разрешение INTERNET**.
- Вызов через стандартный `Intent.ACTION_ASSIST` — открывается помощник, которого назначил пользователь.
- Foreground service с постоянным системным уведомлением и кнопкой остановки. После распознавания сервис освобождает микрофон на 20 секунд.
- Экран учитывает системные отступы для статус-бара, вырезов и экранной клавиатуры, в том числе на Android 15 и HyperOS.
- Сборка APK в GitHub Actions; CI проверяет и unit-тесты, и наличие **подлинной модели с закреплённой SHA-256** внутри готового APK.

## Установка и проверка

1. Назначьте нужного цифрового помощника по умолчанию в настройках Android.
2. На странице **Actions → Android CI** скачайте артефакт `hotword-debug-apk` из успешной сборки. Распакуйте ZIP и установите APK.
3. Откройте приложение и дождитесь **локальной распаковки** встроенной модели; при первой подготовке необходимо свободное место во внутреннем хранилище. Скачивание по сети не выполняется.
4. Введите любую русскую фразу и нажмите **«Проверить системного помощника»**. Затем разрешите использование микрофона и нажмите **«Начать прослушивание»**.
5. Проверьте с открытым приложением, в другом приложении и с погашенным экраном. Если автоматический вызов заблокирован Android, посмотрите уведомление с ручным действием.

После перезагрузки устройство не перезапускает микрофонный сервис автоматически. Чтобы сменить фразу, остановите прослушивание, введите новую и запустите его снова.

## Сборка из исходников

Требуется JDK 17, Android SDK Platform 35 и Gradle 8.13. В Git **не хранится сторонний архив модели** размером около 45 МБ: скрипт загружает его **на машине сборки**, проверяет контрольную сумму и помещает в assets, после чего модель автоматически встраивается в APK.

```sh
bash scripts/prepare-bundled-model.sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

При отсутствии доступа в интернет на машине сборки вручную положите **именно** `vosk-model-small-ru-0.22.zip` в `app/src/main/assets/models/ru.zip`. Ожидаемая SHA-256 находится в `models/ru.sha256`; Gradle отклоняет неверный или отсутствующий архив. GitHub Actions выполняет подготовку автоматически, а затем проверяет контрольную сумму **внутри APK**. Это build-time операция; готовому приложению сеть не нужна.

## Известные ограничения

- `ACTION_ASSIST` не обходит ограничения Android на запуск Activity из фона. На заблокированном экране выбранный помощник также может не начать прослушивание автоматически. Уведомление — резервный путь, но не замена hands-free.
- Пока поддерживается **только русский** язык. **Фраза** настраиваемая, но поддержка других языков отложена.
- В MVP используется непрерывное ASR (Vosk), а не энергоэффективный keyword spotter. Возможны ложные срабатывания, пропуски и повышенный расход аккумулятора.
- Первая локальная подготовка модели требует свободного места. Доступность помощника с заблокированного экрана на Xiaomi 14 / HyperOS нужно проверить на реальном устройстве.

## Архитектура

```text
Bundled APK model (models/ru.zip) → ModelInstaller → Internal storage
                                                      ↓
MainActivity → Preferences → WakeWordService → WakeWordEngine (Vosk)
                                               ↓ matches phrase
                                         release microphone
                                               ↓
                                    AssistantLauncher (ACTION_ASSIST)
```

`WakeWordEngine` выделен интерфейсом для будущих low-power движков. `ModelLanguage` позволяет расширять список встроенных языковых моделей; пока в нём одна запись. `AssistantLauncher` не знает о конкретном поставщике помощника.
