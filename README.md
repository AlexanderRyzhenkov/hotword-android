# Hotword

**Русский** · [English](README.en.md)

Hotword — открытое Android-приложение для локального распознавания настраиваемой русской ключевой фразы и запуска **системного голосового помощника, выбранного пользователем по умолчанию**. Приложение не привязано к конкретному поставщику помощника.

## Версия 0.5.0 — PocketSphinx KWS

В режиме ожидания Hotword больше не запускает полноценное распознавание речи Vosk. Вместо него используется **PocketSphinx keyword spotting**: декодер ищет только одну заданную ключевую фразу. Цель изменения — значительно снизить постоянную загрузку CPU и расход батареи.

Русская акустическая модель CMUSphinx включается в APK на этапе сборки. Библиотека PocketSphinx Android также фиксируется на конкретной версии исходного артефакта. Телефон ничего не скачивает и приложению не требуется разрешение `INTERNET`.

### Произвольная русская фраза

Пользователь по-прежнему может менять ключевую фразу без переобучения модели.

Hotword нормализует кириллический текст и на устройстве строит маленький PocketSphinx pronunciation dictionary только для слов текущей фразы. Поскольку русская акустическая модель различает ударные и безударные гласные, а пользователь не должен вручную ставить ударение, для каждого слова автоматически создаются альтернативы со всеми возможными позициями ударения. Для `ё` ударение считается заданным.

Пример:

```text
"привет помощник"
        ↓
runtime G2P
        ↓
несколько вариантов произношения слов
        ↓
PocketSphinx single-keyphrase search
```

В 0.5.0 ключевая фраза должна содержать русские слова. Знаки препинания и дефисы используются как разделители.

## Возможности

- Офлайн-распознавание ключевой фразы.
- Настраиваемая русская фраза без обучения новой модели.
- Запуск только системного помощника, выбранного в Android по умолчанию.
- Работа в фоне и с выключенным экраном через microphone foreground service.
- Опциональный короткий звуковой сигнал после срабатывания.
- Проверка необходимых разрешений и системных настроек перед запуском.
- Повторная проверка доступа во время работы.
- Локальная техническая диагностика без записи аудио или распознанной речи.

## Первичная настройка

Hotword запускает постоянное прослушивание только после выполнения обязательных пунктов:

1. **Микрофон**.
2. **Уведомления**.
3. **Запуск помощника из фона** — Android special access «Поверх других окон».
4. **Работа без ограничений батареи**.
5. **Фоновая работа приложения**.

После возврата из системных настроек состояние проверяется автоматически. Если необходимый доступ позже изменится, Hotword фиксирует это в диагностике и, когда возможно, показывает предупреждение.

## Расход батареи

Предыдущая реализация на непрерывном Vosk ASR показала высокий фоновый расход на реальном устройстве: около 22% доли системной статистики батареи за тестовый период, 1 ч 38 мин CPU и почти 8 часов активного режима. PocketSphinx 0.5.0 выпущен именно для сравнительного теста.

Для корректного сравнения рекомендуется оставить телефон в похожем режиме на несколько часов и сравнить:

- долю расхода Hotword;
- CPU time;
- active time;
- пропуски ключевой фразы;
- ложные срабатывания.

Постоянный `PARTIAL_WAKE_LOCK` в этой версии намеренно сохранён, чтобы сравнение с предыдущей версией меняло главным образом движок распознавания. Его влияние на deep sleep можно исследовать отдельно.

## Сигнал распознавания

После успешного распознавания Hotword может воспроизвести короткий двухтональный сигнал перед передачей микрофона помощнику. Сигнал синтезируется кодом приложения и может быть отключён в настройках.

## Конфиденциальность

- Аудио обрабатывается локально.
- Аудио не сохраняется.
- Аудио и распознанный текст не отправляются в сеть.
- Приложение не запрашивает `INTERNET`.
- Диагностика хранит только технические события жизненного цикла.

## Ограничения

PocketSphinx использует классическую HMM/GMM-архитектуру. Она значительно уже по задаче, чем полноценный ASR, но чувствительность к шуму, голосу и конкретной фразе необходимо проверить на реальных устройствах. Порог KWS в 0.5.0 выставлен консервативно и может быть скорректирован после тестов false-positive / miss-rate.

После полной перезагрузки Android 14+ требуется один раз открыть Hotword, прежде чем microphone foreground service снова сможет работать постоянно.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.13.

```sh
bash scripts/prepare-pocketsphinx.sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

Скрипт сборки загружает фиксированный PocketSphinx Android AAR и официальный русский акустический пакет CMUSphinx, проверяет зафиксированные идентификаторы/контрольную сумму и помещает в APK только необходимые акустические файлы. Большие бинарные build-inputs не хранятся в Git.

## Архитектура

```text
WakeWordService
 ├─ PocketSphinxWakeWordEngine
 │    ├─ single-keyphrase search
 │    └─ RussianPronunciation (runtime G2P)
 ├─ TriggerChime
 ├─ AssistantLauncher
 └─ Diagnostics
```

`WakeWordEngine` остаётся интерфейсом между сервисом и детектором ключевой фразы, поэтому движок можно менять без переделки логики запуска помощника.
