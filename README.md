# Hotword

**Русский** · [English](README.en.md)

Hotword — открытое Android-приложение для локального распознавания настраиваемой русской ключевой фразы и запуска **системного голосового помощника, выбранного пользователем по умолчанию**. Приложение не привязано к конкретному поставщику помощника.

## Возможности

- Русская офлайн-модель Vosk встроена в готовый APK. После установки телефону не нужен интернет для распознавания.
- Ключевая фраза настраивается пользователем и применяется автоматически.
- Прослушивание работает через microphone foreground service без кнопок «Старт»/«Стоп».
- После распознавания можно включить короткий двухтональный сигнал подтверждения; по умолчанию он включён.
- Запускается только помощник, выбранный в Android по умолчанию. Неявное меню выбора нескольких помощников не используется.
- Перед первым запуском фонового прослушивания приложение проверяет необходимые разрешения и системные настройки.
- Во время работы приложение продолжает проверять необходимые настройки и предупреждает, если доступ был отозван или изменён.
- Есть локальная диагностика жизненного цикла сервиса. Аудио и текст распознанной речи в диагностику не записываются.

## Первичная настройка

Hotword не запускает постоянное прослушивание, пока не выполнены все обязательные пункты:

1. **Микрофон** — нужен для локального распознавания.
2. **Уведомления** — используются для обязательного уведомления foreground service и предупреждений о проблемах настройки.
3. **Запуск помощника из фона** — Android special access «Поверх других окон». Hotword не рисует overlay-окна; разрешение используется для допуска фонового запуска выбранного помощника.
4. **Работа без ограничений батареи** — уменьшает вероятность остановки длительного распознавания системой.
5. **Фоновая работа приложения** — Android не должен считать приложение ограниченным в фоне.

Состояние каждого пункта отображается прямо в приложении. После возврата из системных настроек проверка выполняется повторно автоматически. Если обязательный доступ позже пропадёт, Hotword фиксирует это в диагностике и, когда уведомления доступны, показывает предупреждение.

> Android предоставляет не одинаковые страницы настроек на всех устройствах. Hotword использует только публичные Android API и стандартные Intent для открытия доступных системных настроек.

## Сигнал распознавания

При успешном распознавании ключевой фразы Hotword может воспроизвести короткий сигнал «ту-дум» перед передачей микрофона помощнику. Его можно отключить в главном экране.

Для исследования UX были просмотрены открытые наборы notification sounds, включая [akx/Notifications](https://github.com/akx/Notifications), опубликованный в том числе под CC0. В приложение сторонний аудиофайл **не включён**: финальный сигнал синтезируется кодом Hotword из двух затухающих тонов. Это не требует отдельной лицензии на аудио-ассет.

## Иконка

Новая иконка — оригинальный знак Hotword: вертикальная звуковая волна и дуга отклика на тёмном фоне. Реализованы обычная, круглая, adaptive и monochrome-версии для современных Android launchers. Этот же знак используется в системном уведомлении.

## Конфиденциальность

- Аудио обрабатывается локально.
- Аудио не сохраняется.
- Аудио и распознанный текст не отправляются на сервер.
- Приложение не запрашивает разрешение `INTERNET`.
- Локальная диагностика хранит только технические события, например запуск сервиса, срабатывание ключевой фразы и ошибки жизненного цикла.

## Ограничения Android

Hotword — обычное стороннее приложение, а не системный компонент Android. Вызов помощника выполняется публичными Android Intent и зависит от того, предоставляет ли выбранный помощник подходящий экспортированный обработчик.

После полной перезагрузки устройства Android 14+ не разрешает обычному приложению автоматически запустить microphone foreground service непосредственно из `BOOT_COMPLETED`. Поэтому после перезагрузки требуется один раз открыть Hotword.

Foreground service требует постоянного системного уведомления. На Android 13+ само разрешение `POST_NOTIFICATIONS` не является обязательным для создания foreground service, но Hotword считает уведомления обязательной частью настройки, чтобы пользователь видел состояние длительной работы и предупреждения.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.13.

```sh
bash scripts/prepare-bundled-model.sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

Русская модель не хранится в Git. Сборочный скрипт загружает закреплённый архив, проверяет SHA-256 и добавляет его в APK на этапе сборки. CI повторно проверяет модель уже внутри готового APK.

## Архитектура

```text
MainActivity
 ├─ SetupRequirements / DeviceSetup
 ├─ Preferences
 └─ WakeWordService
      ├─ VoskWakeWordEngine
      ├─ TriggerChime
      ├─ AssistantLauncher
      └─ Diagnostics
```

`WakeWordEngine` остаётся заменяемым: непрерывный Vosk ASR можно позже заменить специализированным low-power keyword spotter.
