# Hotword Android

**Русский** · [English](README.en.md)

Открытый Android-проект: распознаёт **любую настраиваемую ключевую фразу** локально и пытается вызвать **системного голосового помощника, выбранного пользователем**. Приложение не связано ни с Алисой, ни с Google, ни с другим поставщиком.

> **MVP — проверка гипотезы.** Android может запретить открытие системного помощника из фонового приложения, в особенности при заблокированном экране. Поэтому мы не обещаем полностью бесконтактную работу на всех устройствах. После срабатывания появляется уведомление с действием «Открыть помощника» на случай блокировки автоматического запуска.

## Возможности MVP

- Собственная фраза (например, «привет помощник»), русский или английский язык (США). Слова должны распознаваться выбранной языковой моделью.
- Полностью локальная обработка микрофона через [Vosk](https://alphacephei.com/vosk/); аудио не отправляется на сервер и не сохраняется.
- Открытие только стандартного Android-действия `Intent.ACTION_ASSIST`, без захардкоженного пакета помощника.
- Явно запускаемый `foreground service` с индикатором в системе, кнопкой остановки и освобождением микрофона на 20 секунд после совпадения.
- Однократная загрузка офлайн-модели с Vosk и резервных зеркал: повторы после таймаута, возобновление частичной загрузки, отображение прогресса и проверка SHA-256. Если серверы недоступны — импорт скачанного ZIP через системный выбор файла.
- CI через GitHub Actions и APK в артефактах успешной сборки.

## Установка и тестирование

1. Назначьте нужного **цифрового помощника по умолчанию** в настройках Android.
2. Откройте проект в Android Studio (JDK 17, Android SDK 35, Gradle 8.13) либо запустите `gradle :app:assembleDebug`. В MVP Gradle Wrapper не включён; в GitHub Actions Gradle устанавливается автоматически.
3. Установите `app-debug.apk`. На первом экране нажмите **«Проверить системного помощника»**: сначала убедитесь, что выбранный вами помощник открывается вручную.
4. Выберите язык, введите фразу и нажмите **«Загрузить офлайн-модель»**. При обрыве сети повторите загрузку: приложение продолжит с сохранённого места, если сервер поддерживает HTTP Range, и попробует другие зеркала. Интернет нужен только для первоначальной установки модели; архивы занимают 40–50 МБ.
   - Если все сайты недоступны, скачайте правильный ZIP на другом устройстве по [официальной странице моделей Vosk](https://alphacephei.com/vosk/models) (русский `vosk-model-small-ru-0.22.zip` или английский `vosk-model-small-en-us-0.15.zip`), перенесите его на телефон и выберите **«Импортировать модель из ZIP»**. Приложение проверит SHA-256, извлечёт и установит модель без сети.
5. Разрешите микрофон (уведомления желательны), нажмите **«Начать прослушивание»**. Проверьте распознавание сначала с открытым экраном, затем в другом приложении и, наконец, с выключенным экраном.
6. Если помощник не открылся автоматически, проверьте уведомление о распознанной фразе. После изменения языка/фразы остановите и снова запустите сервис.

APK после CI: **Actions → Android CI → Artifacts → hotword-debug-apk**. Скачайте ZIP и извлеките APK.

## Ограничения

- Android 10+ ограничивает запуск `Activity` из фона **даже для foreground service**. `ACTION_ASSIST` не обходит эти ограничения; экран блокировки и оболочки вроде HyperOS требуют практической проверки. В некоторых случаях появится только уведомление.
- `ACTION_ASSIST` вызывает системно выбранного помощника, но **не гарантирует**, что тот автоматически откроет микрофон или выполнит команду без разблокировки экрана.
- MVP использует потоковое **распознавание речи (ASR)** с проверкой фразы, а не специализированную низкопотребляющую модель hotword. Ожидаются ложные срабатывания, пропуски и дополнительный расход батареи. Предпочтительны длинные, редкие фразы. Не все слова есть в моделях.
- Сервис необходимо включить вручную. После перезагрузки или принудительной остановки Android не гарантирует автоматический запуск микрофона из фона. Параметры энергосбережения Xiaomi также могут остановить процесс.
- Не тестировалось на Xiaomi 14 и не подтверждено успешной сборкой до первого запуска CI. Это исходный прототип для тестирования, а не готовый релиз.

## Архитектура

```text
MainActivity ──> Preferences + ModelInstaller
     │
     └──> WakeWordService (microphone foreground service)
                     │
                     └──> WakeWordEngine (Vosk adapter)
                                │ detected
                                ▼
                         release microphone
                                │
                                └──> AssistantLauncher (ACTION_ASSIST)
```

Компонент распознавания выделен интерфейсом `WakeWordEngine`, чтобы позднее заменить Vosk более экономным движком. Системный запуск изолирован в `AssistantLauncher`.

## Безопасность

Аудио остаётся на телефоне и не записывается на диск. Интернет-доступ нужен только для скачивания моделей, ручной импорт возможен офлайн. Установка проверяет зафиксированный SHA-256 официальных ZIP-архивов для защиты от битых/подменённых файлов. Постоянное уведомление указывает на использование микрофона, сервис можно остановить. Приложение не запрашивает Accessibility и не пытается обходить системные ограничения.
